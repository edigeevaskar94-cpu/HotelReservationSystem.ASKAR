# Hotel Reservation System

## 📌 Project Description
Hotel Reservation System is a **console-based Java application** developed as part of **Assignment 2**.  
The project represents a simple hotel room reservation system that allows users to interact with hotel data via the command line.

The main purpose of this project is to demonstrate:
- Object-Oriented Programming (OOP) in Java
- Work with classes and objects
- Console input/output
- Basic application logic and structure

---

## 🛠 Technologies Used
- Programming Language: **Java**
- Java Version: **JDK 8+**
- Application Type: **Console Application**
- IDE: **IntelliJ IDEA / Eclipse / VS Code**
